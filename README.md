# SVGviewer
Программа для локального просмотра и подбора SVG файлов (иконок)

<img width="1604" height="1035" alt="image" src="https://github.com/user-attachments/assets/4766d8fc-e4a8-4738-aaef-5e3a95b0c3fc" />
Имеет удобное настраиваемое окно с выравниванием элементов UI.
Имеет функцию нормализации svg иконок - подгоняет под размер 1024x1024px по умолчанию.
Обрабатывает текущий файл или всю папку.
Может копировать код scg иконки для разных языков программирования.
Экспортирует в png, ico, jpg и пересохраняет в svg.
