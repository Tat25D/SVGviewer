🖼️ SVG_ICO_VIEWER
SVG_ICO_VIEWER — это мощное настольное приложение для разработчиков и дизайнеров, предназначенное для удобного просмотра, нормализации и экспорта SVG-иконок. Создано с использованием Python и PyQt6.
<br>
Приложение решает частую проблему при работе с векторными иконками: автоматическую адаптацию цвета под светлую/темную тему интерфейса, пакетную нормализацию размеров и быстрый экспорт в растровые форматы (PNG, ICO, JPG) с сохранением идеального центрирования.
<br>
✨ Основные возможности<br>
<br>
📂 Умный просмотр и навигация<br>
Адаптивная сетка: Иконки автоматически выстраиваются в сетку (Flow Layout), подстраиваясь под ширину панели. Длинные имена файлов переносятся на 2-3 строки.
Текстовый поиск: Мгновенная фильтрация иконок по имени.<br>
Авто-исправление раскладки: Если вы случайно начали печатать запрос на русской раскладке, кнопка "Я-Z" мгновенно переведет текст в английский.
Навигация по списку: Удобная панель со стрелками (вверх/вниз по странице, в самое начало/конец списка).
<br>
🎨 Предпросмотр и зум<br>
Точная система координат: Иконка всегда отцентрирована математически, независимо от изменения размера окна или перемещения разделителя (сплиттера).
Опорная сетка: На холст нанесены тонкие линии-ориентиры: крестик в центре и пунктирные квадраты реальных размеров (64px, 128px, 256px, 512px, 1024px, 2048px) для понимания масштаба.<br>
Адаптивный цвет: Программа анализирует яркость SVG и автоматически инвертирует цвет иконки (tint), если она сливается с фоном текущей темы (Dark/Light).
Управление масштабом: Зум колесиком мыши (от центра), кнопками +/- или перетаскиванием холста средней кнопкой мыши.<br>
⚙️ Нормализация и Экспорт<br>
Авто-нормализация (1024x1024): Кнопки нормализации одного файла или всех файлов в папке. Приложение проставляет атрибуты width, height (1024) и добавляет viewBox, если он отсутствует, сохраняя пропорции иконки.<br>
Мультиформатный экспорт: Сохранение выбранной иконки в PNG, ICO, JPG или оригинальный SVG.<br>
Мультиразмерный экспорт: Возможность выбрать сразу несколько размеров (от 16x16 до 1024x1024) или выгрузить "Все размеры" одной пачкой (файлы получат суффикс _16x16 и т.д.).<br>
Адаптивный фон: При экспорте в JPG (который не поддерживает прозрачность) автоматически подставляется белый фон.<br>
📋 Интеграция с кодом<br>
В один клик скопируйте код иконки в буфер обмена в нужном формате:<br>
Copy PNG — копирует растровое изображение (с инвертированным под тему цветом) для прямой вставки в графические редакторы (Photoshop, Figma).<br>
Copy Python — оборачивает код в строковый литерал svg_code = """...""".<br>
Copy JS — оформляет как const svgCode = \...`;`.<br>
Copy JSON — собирает в JSON-объект.<br>
Copy HTML — копирует чистый SVG-код.<br>
🚀 Как пользоваться
<br>
1. Установка и запуск
Убедитесь, что у вас установлен Python 3.9+. Клонируйте репозиторий и установите зависимости:<br>
git clone https://github.com/ВАШ_НИК/SVG_ICO_VIEWER.gitcd SVG_ICO_VIEWERpip install PyQt6<br>
Запустите приложение:<br>
python main.py<br><br>
Либо скачайте exe файл
<br><br>
2. Добавление иконок<br>
При первом запуске программа автоматически создаст папку SVG в директории скрипта. Поместите туда ваши .svg файлы. Нажмите кнопку Обновить (иконка круговой стрелки) на верхней панели, чтобы перечитать папку.
<br>
3. Использование верхней панели инструментов<br>
Верхний ряд кнопок (без текста, только иконки):
<br>
🔄 Обновить: Перезагрузить список иконок из папки.<br>
🌗 Тема: Переключение между светлой и темной темой.<br>
🔁 Нормализовать текущую: Приводит выбранную иконку к размеру 1024x1024.<br>
🔁 Нормализовать все: Применяет нормализацию ко всем файлам в папке SVG.<br>
💾 Экспорт: Открывает диалоговое окно сохранения в выбранных форматах и размерах.<br>
4. Диалоговое окно экспорта<br>
Выберите нужные размеры (например, 32x32 и 64x64) или отметьте "All" для экспорта всех размеров разом.
Выберите формат (PNG, ICO, JPG, SVG).<br>
Нажмите на кнопку формата, выберите папку для сохранения.<br>
(Если выбрано несколько размеров, программа автоматически создаст несколько файлов с соответствующими суффиксами).<br>
🛠 Технологии и архитектура<br>
Фреймворк: PyQt6<br>
Графика: QtSvg, QGraphicsView (кастомный движок центрирования, обходящий баги скроллбаров Qt).<br>
Парсинг: xml.etree.ElementTree для безопасной нормализации SVG-файлов без разрушения структуры.<br>
Архитектура: Разделена на логические модули (viewer_ui для интерфейса, viewer_actions для бизнес-логики, theme_manager для стилизации, и отдельные виджеты).
